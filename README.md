# Ore Cutter

A Fabric and NeoForge mod (and a plain data pack) for Minecraft 26.3. **Any ore block becomes its deepslate twin in the stonecutter.**

You mined a diamond ore with Silk Touch and want it on the cellar wall, but the light stone one
looks wrong against the deepslate. Put it in the stonecutter: an ore in, its deepslate twin out,
and back again. No new ore is ever made, so there is nothing to farm. It is just the block you
already have, in the colour your build needs.

## What it does

- **All eight ores, both ways.** Coal, copper, iron, gold, redstone, emerald, lapis and diamond ore
  each cut to their deepslate twin, and each deepslate ore cuts back. One block in, one block out.
- **One click, in a block you already own.** No new blocks, items, screens or settings.
- **Nothing to farm.** You still need the ore block first (Silk Touch, same as vanilla). The mod
  never makes ore from ingots or raw material.
- **Server side.** On a server, only the server needs it; players with a vanilla game can join and
  use the recipes.

## Which file?

- **Fabric:** `ore-cutter-fabric-<version>.jar`, with [Fabric API](https://modrinth.com/mod/fabric-api).
- **NeoForge:** `ore-cutter-neoforge-<version>.jar`.
- **No mod loader:** `ore-cutter-<version>-datapack.zip` goes in your world's `datapacks` folder.
  It holds the same recipes.
